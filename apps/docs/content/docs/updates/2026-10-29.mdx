## pnpm 12

The source checkout and newly composed projects now pin pnpm 12.16.1. Node.js 24 remains the supported application runtime.

Peer deduplication keeps shared Next.js runtime classes consistent across application and package middleware.

Dependency build permissions use pnpm's `allowBuilds` setting. Existing allowed and blocked build scripts retain their permissions, and the Drupal dependency patches work with pnpm 12's patch parser.

For an existing customer-owned project, update its pnpm pin, follow the [pnpm migration guide](https://pnpm.io/migration), and run `pnpm install` to refresh the lockfile. Configuration environment variables now use the `PNPM_CONFIG_` prefix. Review and commit the resulting manifest, workspace settings, and lockfile changes.
