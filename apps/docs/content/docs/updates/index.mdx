## August 26, 2026

### Compose a project with `create-next-hydra`

`create-next-hydra` 0.2.0 lets you start from a complete preset, choose providers individually, include compatible add-ons, change a Maintainer Workspace's composition, and install ShadCN registry items into projects you already own.
